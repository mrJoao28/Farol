# Identidade visual — Farol / Vigia

Direção escolhida: **Vigia**. Fundo verde-escuro `#152321`, texto creme `#F2EEE2`, sinal âmbar `#F3B878`, alerta `#FF876E` e êxito `#BDD69B`.

- `farol-mark.svg`: símbolo transparente, para contextos sobre fundo escuro.
- `farol-lockup.svg`: assinatura horizontal do produto, para fundo escuro. Para outros fundos, use uma variante de cor explicitamente ajustada.
- `farol-app-icon.svg`: ícone quadrado para app e avatar. Gerar favicon raster a partir deste arquivo quando implementar a interface.
- `farol-hero.svg`: arte de abertura, utilizável como plano de fundo ou seção visual; reserve áreas para texto e teste contraste no layout real.

O símbolo representa uma torre e dois feixes de luz; mantém formas largas para funcionar em tamanhos pequenos. O arquivo do símbolo não inclui fundo, e as cores ficam codificadas nos SVGs para preservar a identidade em qualquer renderização.

**Estado:** proposta de identidade a ser validada no contexto das telas. Estes são ativos visuais; o produto ainda não foi implementado.
